Описание проекта
«Посмотри в окно» — проект из модуля CSS-стилизации курса Fullstack Developer от Yandex Practicum (спринт 2). Это интерактивное веб-приложение для просмотра видео: галерея карточек с роликами, плеер, поиск по параметрам и подгрузка контента. Я доработал CSS в файле style.css, чтобы интерфейс соответствовал макету — от лейаута до состояний элементов (hover, focus, active). Функциональность (JS-логика, шаблоны <template>) уже готова: поиск, смена видео, прелоадеры, ошибки.

Приложение имитирует "окно в мир" — видео загружаются из внешнего API, с фильтрами и бесконечной прокруткой. Фокус на дизайне: фиксированные размеры, кастомные формы, чекбоксы и скроллбар.

Возможности
Галерея видео: Карточки с thumbnail, названием и описанием; клик меняет видео в плеере.
Поиск и фильтры: Форма с инпутом и чекбоксами (HD, 4K, YouTube); результаты обновляют галерею.
Подгрузка: Кнопка "Показать ещё" добавляет 5 карточек.
Состояния: Hover (подчёркивание), active (цвет фона), focus-visible (outline); кастомные чекбоксы и инпут.
Прелоадеры и ошибки: Анимация загрузки поверх плеера/списка; блок ошибки при сбоях.
Доступность: Visually-hidden для лейблов, cursor: pointer, :focus-visible.
Адаптив: Фиксированные размеры, но скролл в контейнере; object-fit для видео/thumbnail.

Технологии
Верстка:
HTML5 (<template> для динамики, семантика: section, form, video).
CSS3 (Flex/Grid для лейаута, gap, object-fit/position, line-clamp, :has() для фокуса, pseudo-elements для чекбоксов).


Шрифты: Готовые (fonts.css), глобальный font-family.
JS: Готовый скрипт (fetch API, event listeners, шаблоны); не трогала.

Инструменты:
Figma (макет).
Git/GitHub (версионный контроль).



Чистый vanilla, без фреймворков. Фиксированные px/rem для брутальности.
